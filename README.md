# Energy Drink Mixer

## Project Overview

The Energy Drink Mixer is an academic innovation project developed at Saveetha Institute of Medical and Technical Sciences during the 2022–2023 academic year.

The project explores an automated drink-mixing solution designed to support customized flavours and convenient preparation.

## Problem Statement

Preparing customized drinks manually can take time and may lead to inconsistent preparation. This project explores automation as a way to make the drink-mixing process more convenient.

## Proposed Solution

The proposed system focuses on automating the drink-mixing process while allowing users to choose their preferred flavours.

## Key Features

- Automated drink-mixing concept
- Customizable flavour options
- Focus on convenient drink preparation
